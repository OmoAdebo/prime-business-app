# Prime

Prime is an all-in-one business management platform designed to simplify operations for SMEs, SMBs, NGOs, and corporate organizations.

## Core Features

- **Simple Bookkeeping**: Automatic accounting and financial tracking
- **Smart Inventory**: Real-time stock tracking across multiple locations
- **Debt & Credit Tracking**: Manage debts and credits efficiently
- **Team & Payroll**: Employee attendance and payroll management
- **Banking & Budgeting**: Built-in business account and financial limits

## Growth Tools

- **Instant Online Store**: Launch a digital shop integrated with inventory
- **Access to Capital**: Business loans based on turnover and health
- **Hybrid Connectivity**: Work offline and sync when online

## Perfect For

- Retailers
- Wholesalers
- Service providers
- Organizations needing streamlined management

## Original Oreone Foundation

This project is built upon the Oreone Financial Management System, a comprehensive financial management solution designed for businesses in Nigeria.

### Original Oreone Modules

- **Dashboard**: Get a quick overview of your business with key metrics and insights
- **Banking**: Manage bank accounts, transactions, and financial activities with Nigerian Naira (₦) as the default currency
- **Bookkeeping**: Record and manage financial transactions and accounts
- **Inventory**: Track and manage product inventory and stock levels
- **Customers**: Manage customer information and relationships
- **Employees**: Manage employee information, payroll, and HR functions
- **Credit & Debt**: Manage credit accounts, loans, and debt tracking
- **Budgeting**: Create and manage budgets and financial planning
- **Online Store**: Manage e-commerce operations and online sales
- **Store Management**: Manage physical retail locations and operations
- **Reports**: Generate and view financial and business reports
- **Loans**: Manage loan applications, approvals, and tracking
- **Settings**: Configure application settings and preferences

### Admin Features

SuperAdmin and Admin users have access to additional features:

- Create and manage bank accounts for employees and customers
- Set account permissions and spending limits
- Monitor account activity and balances
- Freeze or unfreeze accounts as needed
- Generate administrative reports

### Currency

The default currency is Nigerian Naira (₦). All monetary values are displayed in Naira by default.

### System Review

A comprehensive system review is available at `/system-review` to track the status of all modules and features.

## System Requirements

- Node.js 16.x or higher
- npm 8.x or higher
- Modern web browser (Chrome, Firefox, Safari, Edge)

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
4. Open your browser and navigate to http://localhost:5173

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm test` - Run tests
- `npm run test:watch` - Run tests in watch mode
- `npm run lint` - Run ESLint
